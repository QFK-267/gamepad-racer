# 手柄赛车 · Gamepad Racer

一个纯前端的小游戏：开着红色小车在封闭赛道上刷圈速。**插上手柄就能玩**，没手柄也能用键盘。

## 开始玩

双击 `index.html`，或者跑：

```bash
./启动游戏.sh
```

## 操作

| 动作 | 手柄 | 键盘 |
| --- | --- | --- |
| 转向 | 左摇杆左右 | ← → / A D |
| 油门 | RT（或左摇杆上） | ↑ / W |
| 刹车 · 倒车 | LT（或左摇杆下） | ↓ / S |
| 手刹漂移 | A | 空格 |
| 回到起点 | B | R |
| 暂停 / 继续 | Start | Esc / 回车 |
| 静音 | — | M |

> 手柄必须先在页面上**按一下任意键**，浏览器才会把 `gamepadconnected` 事件发出来（这是浏览器的安全策略，不是 bug）。左上角会显示已识别的手柄名字。

## 玩法

- 沿着赛道跑，压过起点线计一圈，右上角显示圈速、最快圈和上一圈。
- 青色光带是检查点，只有按顺序通过才会计圈（抄近道不算）。
- 冲出路面会上草地：抓地力骤降、车速暴跌，再往外会撞上护栏并掉速。
- 镜头跟着车头转，**车头永远朝屏幕上方**（小地图仍固定北朝上，车是带朝向的小箭头）。
- 速度表下方彩条实时反映车速；高速时镜头会自动拉远。
- 默认音效是引擎声，按 M 开关。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构（画布 + HUD + 菜单层） |
| `style.css` | HUD / 菜单的毛玻璃样式 |
| `game.js` | 全部游戏逻辑：输入、车辆物理、赛道、计圈、渲染 |
| `tools/headless-test.js` | 无头冒烟测试：假 DOM + 假手柄跑主循环，含自动驾驶验证计圈 |

## 自测

```bash
node tools/headless-test.js
```

用假的 Canvas / DOM / 手柄跑一万三千多帧，检查是否有运行时异常，并让自动驾驶跑几圈来验证检查点和计圈逻辑：

```
自动驾驶: 9000 帧, 最大横向偏移 51, 出界帧 0
比赛状态: 圈数=10 最快=13.91 上一圈=13.91
✅ 全程无运行时错误
```

## 想自己改？

- 赛道形状：`game.js` 里的 `CTRL`（Catmull-Rom 控制点，闭合回路）。
- 路宽 / 护栏：`HALF_W`、`WALL`。
- 手感：`MAXSPEED`、`ENGINE`、`GRIP_ROAD`、`TURN_RATE` 等常量。
- 视角：`CAM_HEAD_UP = true` 是「车头朝上」的跟随镜头，改成 `false` 就回到固定的北朝上视角。
- 浏览器控制台里有调试钩子 `__racer`，例如 `__racer.race.laps`、`__racer.car`、`__racer.startRace()`。
